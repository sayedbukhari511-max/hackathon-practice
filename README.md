## ⚙️ Getting Started

Follow these steps to run a project locally.

### Prerequisites

Install the following tools:

- [Node.js](https://nodejs.org/)
- [Git](https://git-scm.com/)
- [Visual Studio Code](https://code.visualstudio.com/)

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/hackathon-practice.git
```

### 2. Navigate to the Project Folder

```bash
cd hackathon-practice
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL shown in your terminal to view the application in your browser.
